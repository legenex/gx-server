What is covered

GX Cluster source, four-mode gateway/LiteLLM, Postgres dumps, OpenWebUI volume, AgentOS, systemd user units, secrets, scripts, docs, model manifests. Public weights are recreated from models.lock. GX-Playground/media are in history, not in the normal production recovery recipe.

Cross-node encrypted restic is not geographic/offsite disaster recovery. Losing both GX10s loses mutable data.

Destructive restore from this page requires typing RESTORE on the command line; the UI only starts backup and verify.

Guides: docs/DISASTER-RECOVERY.md and docs/GX-BACKUP-RESTORE-GUIDE.pdf in the gx-backup repository.
