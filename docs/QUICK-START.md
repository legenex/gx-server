# Quick start

```
gx status
gx backup
gx doctor
gx models
gx auto
gx mini
gx code
gx max
gx logs
gx benchmark
```

Gateway: `http://127.0.0.1:4000/v1` (Tailscale `http://100.105.214.61:4000/v1`)

OpenWebUI: `http://127.0.0.1:3000`

GX-Cluster: `http://127.0.0.1:8088`

Models to send: `gx-auto` (default), `gx-mini`, `gx-code`, `gx-max`.

Restic password lives at `~/.config/gx-backup/restic-password` on both nodes (mode 0600).
